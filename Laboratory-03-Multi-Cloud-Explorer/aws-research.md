# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a broad cloud platform launched in 2006. It provides on-demand services for computing, storage, databases, networking, security, analytics, AI/ML, and many other workloads.

## Global Infrastructure
AWS operates a large global infrastructure organized into geographic Regions and Availability Zones. This design supports scalability, availability, disaster recovery, and deployment close to customers.

## Cloud Management Console
The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services
- Amazon EC2
- Amazon S3
- Amazon VPC
- AWS IAM

## Three Advantages
- Broad range of cloud services.
- Large global infrastructure and strong scalability.
- Extensive ecosystem for startups, enterprises, and developers.

## Typical Enterprise Use Cases
AWS is commonly used for web applications, enterprise application hosting, data storage, backup and disaster recovery, analytics, AI/ML, and highly scalable online services.
