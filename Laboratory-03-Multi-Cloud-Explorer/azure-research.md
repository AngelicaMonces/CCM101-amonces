# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's global cloud platform for building, deploying, and managing applications and infrastructure. It supports Windows and Linux workloads as well as open-source technologies such as Kubernetes.

## Global Infrastructure
Azure operates a global infrastructure organized into regions and availability capabilities. Its worldwide network and regional design support performance, reliability, scalability, and data residency requirements.

## Cloud Management Console
The Azure portal is a web-based unified console for creating, managing, monitoring, and configuring Azure resources.

## Four Core Services
- Azure Virtual Machines
- Azure Blob Storage
- Azure Virtual Network
- Microsoft Entra ID

## Three Advantages
- Strong integration with Microsoft's enterprise ecosystem.
- Supports both Windows and Linux workloads.
- Broad enterprise, hybrid-cloud, security, and AI capabilities.

## Typical Enterprise Use Cases
Azure is commonly used for Windows Server migration, Microsoft 365 and identity integration, enterprise applications, hybrid cloud, databases, analytics, AI/ML, and modern application development.
