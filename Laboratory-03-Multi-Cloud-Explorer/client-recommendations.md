# Client Recommendations

## Client A — Startup Company

AWS, because it is a strong choice for a startup with a limited initial budget and expectations of rapid growth. The platform provides scalable services that can be expanded as application demand increases, while allowing the company to avoid large upfront infrastructure investment. AWS also provides services suitable for mobile and web application development.

Services: Amazon EC2, Amazon S3, AWS Lambda, and Amazon RDS.

## Client B — University

Azure, since it is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure also provides strong integration with Microsoft's identity and enterprise technologies, making migration and hybrid-cloud management more straightforward.

Services: Azure Virtual Machines, Microsoft Entra ID, Azure Blob Storage, and Azure SQL Database.

## Client C — AI Research Company

Google Cloud is best, because it fits for an AI research company because of its AI/ML services, data platform, and high-performance infrastructure. It also provides managed Kubernetes through GKE, which can support containerized research workloads.

Services: Vertex AI, Compute Engine, Google Kubernetes Engine (GKE), and Cloud Storage.

## Client D — Global E-Commerce Company

AWS is well suited to a global e-commerce platform that requires highly available and automatically scalable infrastructure. Its global infrastructure and services for compute, load balancing, databases, storage, and autoscaling can support large numbers of customers across regions.

Services: Amazon EC2, Elastic Load Balancing, Amazon RDS/Aurora, Amazon S3, and EC2 Auto Scaling.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, scalability, and flexible infrastructure |
| Enterprise Organization | AWS | Mature ecosystem and extensive enterprise services |
| Microsoft Environment | Azure | Strong Microsoft and hybrid-cloud integration |
| AI / Machine Learning | Google Cloud | Strong AI/ML and data capabilities |
| Kubernetes Deployment | Google Cloud | Strong Kubernetes ecosystem through GKE |
| Global Web Application | AWS | Extensive global infrastructure and scalable services |
