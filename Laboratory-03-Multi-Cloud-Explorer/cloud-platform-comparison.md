# Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |

## Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest range of cloud services and has an extensive service ecosystem. This makes it suitable for organizations with diverse and changing technical requirements.

### 2. Which provider best integrates with Microsoft technologies?
Azure, since it has the strongest integration with Microsoft technologies like Windows Server, Microsoft 365, and Microsoft Entra ID. This makes Azure a natural choice for organizations already invested in Microsoft's ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud is the strongest provider in AI and Kubernetes through Google Kubernetes Engine (GKE). Its technology is closely connected to Google's experience with large-scale distributed systems and Kubernetes.

### 4. Which cloud platform would you personally choose and why?
I choose AWS because of its broad service portfolio, mature ecosystem, and scalability. Its wide range of services would provide flexibility when working on different cloud infrastructure and application requirements. It's also the only cloud service that I know is most popular among tech companies.
