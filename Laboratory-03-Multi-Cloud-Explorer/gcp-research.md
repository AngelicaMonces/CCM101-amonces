# Google Cloud Platform Research

## Brief Overview
Google Cloud is Google's cloud platform for building, deploying, and operating applications and services. It provides infrastructure, data analytics, AI/ML, databases, storage, networking, security, and developer tools.

## Global Infrastructure
Google Cloud organizes its infrastructure into regions and zones across the world. This structure provides options for availability, redundancy, performance, and geographic placement.

## Cloud Management Console
The Google Cloud console is a web-based graphical interface for managing Google Cloud projects, resources, and services.

## Four Core Services
- Compute Engine
- Cloud Storage
- Google Kubernetes Engine (GKE)
- Cloud SQL

## Three Advantages
- Strong AI, machine learning, and data analytics capabilities.
- Deep Kubernetes and container technology expertise.
- Global infrastructure and strong developer tooling.

## Typical Enterprise Use Cases
Google Cloud is commonly used for AI/ML research, data analytics, Kubernetes applications, web applications, databases, and globally distributed services.
